# slozhno-sosredotochitsya-fd

Сложно сосредоточиться — адаптивный сайт, посвящённый проблеме концентрации внимания и способам справляться с отвлекающими факторами.

## О проекте

Проект представляет собой адаптивную веб-страницу, разработанную по готовому дизайн-макету.

Основная задача — создать корректное отображение сайта на различных устройствах, реализовать светлую и тёмную темы оформления и обеспечить автоматический выбор темы в соответствии с системными настройками пользователя.

В работе использован подход Mobile First: разработка начиналась с мобильной версии интерфейса с последующей адаптацией для более широких экранов.

## Основной функционал

-Адаптивное отображение страницы на мобильных устройствах, планшетах и компьютерах.

-Светлая и тёмная темы оформления.

-Автоматическое определение предпочтительной цветовой схемы на основе системных настроек пользователя.

-Возможность переключения между темами.

-Корректное отображение контента и элементов интерфейса при разных разрешениях экрана.

## Что реализовано

-Создана HTML-разметка страницы на основе дизайн-макета.

-Выполнена адаптивная вёрстка по принципу Mobile First.

-Реализовано оформление светлой и тёмной тем.

-Использованы CSS-переменные для управления цветовой схемой.

-Настроено отображение элементов интерфейса для различных размеров экранов.

-Сохранена и интегрирована готовая JavaScript-логика переключения темы из стартового проекта.

## Технологии

-HTML5 — семантическая разметка.

-CSS3 — стилизация и адаптивная вёрстка.

-CSS Custom Properties — управление цветовыми схемами и темами.

-Flexbox и Grid — инструменты построения адаптивных интерфейсов (при наличии в стилях).

-JavaScript — готовая логика переключения тем.

## Структура проекта

index.html — HTML-разметка страницы.

styles/ — таблицы стилей.

scripts/ — JavaScript-логика переключения темы.

images/ — изображения и графические ресурсы.

fonts/ — шрифты проекта.

.github/workflows/ — настройки GitHub Actions.
