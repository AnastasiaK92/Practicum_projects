# posmotri-v-okno-fd

Посмотри в окно — веб-приложение для поиска и просмотра видеороликов с видами из разных городов и мест.

## О проекте

Проект представляет собой интерактивное приложение, в котором пользователь может искать видео по заданным параметрам, просматривать найденные ролики и переключаться между ними.

Основная задача проектной работы — реализовать стилизацию готового приложения в соответствии с дизайн-макетом, используя CSS и сохраняя существующую функциональность JavaScript.

## Основной функционал приложения

-Просмотр видеоролика в основном блоке.

-Отображение списка видео в виде карточек.

-Переключение основного видео при выборе карточки.

-Поиск видео по заданным параметрам.

-Загрузка дополнительных карточек.

-Отображение состояния загрузки с помощью прелоадеров.

-Обработка ошибок при получении данных.

## Что реализовано

-Стилизация интерфейса по готовому макету.

-Оформление основных блоков приложения.

-Работа с CSS для карточек видео, поисковой формы и блока просмотра.

-Сохранение существующей HTML-структуры и JavaScript-логики приложения.

-Согласование визуального оформления с состояниями загрузки и ошибок.

## Технологии

-HTML5 — структура страницы.

-CSS3 — стилизация интерфейса.

-JavaScript — готовая логика приложения.

-Flexbox и Grid — инструменты построения интерфейса (если используются в стилях).

## Структура проекта

index.html — HTML-разметка приложения.

styles/ — стили и оформление интерфейса.

scripts/ — JavaScript-логика приложения.

fonts/ — шрифты проекта.

.github/workflows/ — настройки GitHub Actions.
