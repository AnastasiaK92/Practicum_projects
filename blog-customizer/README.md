# blog-customizer

blog-customizer — веб-приложение для кастомизации внешнего вида страницы блога с помощью интерактивной панели настроек.

## О проекте

Проект представляет собой страницу блога с возможностью изменять оформление статьи через выдвижную боковую панель.

Пользователь может настроить параметры отображения контента, предварительно просмотреть выбранные значения в форме и применить изменения по своему усмотрению.

Основная задача проекта — реализовать удобный механизм кастомизации интерфейса с разделением состояния формы и состояния отображаемой страницы.

## Основной функционал

-Открытие и закрытие боковой панели настроек.

-Закрытие панели при повторном нажатии на кнопку или клике вне панели.

-Настройка внешнего вида статьи через форму.

-Изменение параметров без немедленного применения к странице.

-Применение выбранных настроек по кнопке «Применить».

-Сброс настроек к исходным значениям по кнопке «Сбросить».

-Динамическое изменение оформления статьи с помощью CSS-переменных.

## Особенности реализации

### Управление состоянием

Реализовано разделение состояния формы настроек и состояния отображения страницы.

-Изменения формы сохраняются отдельно от текущего оформления статьи.

-Выбранные параметры применяются к странице только после подтверждения пользователем.

-При сбросе настроек восстанавливаются исходные значения формы и оформления статьи.

### Динамическая кастомизация

Для изменения внешнего вида статьи используются CSS-переменные. Это позволяет динамически обновлять стили без перезагрузки страницы и создания дополнительных CSS-классов для каждого варианта оформления.

### Компонентный подход

Интерфейс построен на React с использованием TypeScript. Для разработки и визуальной проверки компонентов используется Storybook.

## Запуск проекта

Клонировать репозиторий и перейти в папку проекта:

bash

git clone <ссылка-на-репозиторий> cd blog-customizer

Установить зависимости:

bash

npm install

Запустить приложение:

bash

npm run start

Адрес приложения определяется настройками Webpack Dev Server.
