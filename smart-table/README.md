# smart-table

smart-table — интерактивная таблица для просмотра, фильтрации, сортировки и анализа данных о продажах. Приложение позволяет удобно работать с большим количеством записей, быстро находить необходимую информацию и управлять отображением данных с помощью фильтров и постраничной навигации.

Проект разработан в рамках обучения в Яндекс Практикуме.

## О проекте

Основная задача smart-table — предоставить пользователю удобный инструмент для работы с данными о продажах.

Таблица позволяет просматривать информацию о продажах, сортировать записи по различным параметрам, применять фильтры и переключаться между страницами с результатами. Все изменения отображаются динамически без перезагрузки страницы.

## Основной функционал

-Отображение данных о продажах в виде интерактивной таблицы.

-Сортировка записей по выбранным столбцам.

-Фильтрация данных по заданным параметрам.

-Пагинация для навигации между страницами таблицы.

-Динамическое обновление строк таблицы при изменении фильтров.

-Отображение актуальных элементов управления пагинацией.

-Сброс фильтров и восстановление исходного состояния таблицы.

-Обработка пользовательских событий формы.

-Повторный рендеринг таблицы при изменении параметров отображения.

## Реализация функциональности

### Работа с таблицей

Реализовано динамическое формирование строк таблицы на основе исходного набора данных с использованием HTML-шаблонов.

Настроено отображение данных с учётом выбранных пользователем параметров фильтрации и сортировки.

### Фильтрация и сортировка

Реализована обработка изменений параметров формы.

Настроено обновление содержимого таблицы при изменении фильтров.

### Пагинация

Реализована постраничная навигация по данным.

Настроено динамическое формирование кнопок пагинации с учётом количества записей и текущих параметров отображения.

### Обработка событий

Реализована обработка событий change, submit и reset формы.

Настроен единый механизм обновления интерфейса, обеспечивающий синхронное обновление строк таблицы и элементов пагинации.

## Архитектура проекта

Проект построен с использованием модульного подхода.

### Основные директории:

src/ — исходный код приложения.

src/components/ — компоненты таблицы и пользовательского интерфейса.

src/lib/ — вспомогательные функции и утилиты.

public/ — статические ресурсы проекта.

Основная логика приложения сосредоточена в src/main.js, где выполняется подключение, инициализация и взаимодействие компонентов.
