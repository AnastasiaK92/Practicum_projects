# Stellar Burgers

Stellar Burgers — веб-приложение космической бургерной, в котором пользователи могут собирать собственные бургеры из доступных ингредиентов, оформлять заказы и отслеживать их выполнение в режиме реального времени.

Проект представляет собой интерактивное приложение с каталогом ингредиентов, конструктором бургеров, системой авторизации, личным кабинетом и лентой заказов.

## О проекте

Основная задача проекта — реализовать полноценное клиентское приложение с использованием React, TypeScript и Redux. Приложение взаимодействует с серверным API, получает данные об ингредиентах и заказах, обеспечивает авторизацию пользователей и управление глобальным состоянием.

Пользователи могут самостоятельно собирать бургеры, оформлять заказы, просматривать историю покупок и отслеживать статусы заказов.

## Основной функционал

-Просмотр списка ингредиентов, получаемых с сервера.

-Сборка бургера с помощью интерактивного конструктора.

-Добавление булок и начинок в конструктор.

-Изменение порядка ингредиентов.

-Автоматический подсчёт стоимости собранного бургера.

-Оформление заказа для авторизованных пользователей.

-Отображение номера созданного заказа.

-Просмотр подробной информации об ингредиентах в модальных окнах.

-Навигация между страницами с помощью React Router.

-Регистрация, авторизация и выход из аккаунта.

-Защищённые маршруты для авторизованных пользователей.

-Редактирование данных профиля.

-Просмотр общей ленты заказов.

-Просмотр истории заказов пользователя.

-Отображение статусов и стоимости заказов.

-Обновление информации о заказах в режиме реального времени.

## Особенности реализации

### Управление состоянием

Для управления глобальным состоянием приложения используется Redux Toolkit.

Созданы отдельные слайсы для работы с ингредиентами, конструктором бургера, пользователем и заказами.

Асинхронные запросы к серверу реализованы с помощью Redux Toolkit и createAsyncThunk.

Глобальный store обеспечивает централизованное хранение данных и синхронизацию состояния между компонентами приложения.

### Работа с API

Для взаимодействия с сервером используется готовый API-модуль utils/burger-api.ts.

#### Реализованы запросы для:

-Получения списка ингредиентов.

-Создания заказа.

-Получения данных пользователя.

-Регистрации и авторизации.

-Обновления данных профиля.

-Получения ленты заказов.

-Получения истории заказов.

Адрес API задаётся через переменную окружения BURGER_API_URL.

### Маршрутизация и авторизация

Для навигации используется React Router.

Настроены маршруты для конструктора бургера, страницы ингредиента, ленты заказов, профиля пользователя и истории заказов.

Реализована система защищённых маршрутов, ограничивающая доступ к личному кабинету и оформлению заказов для неавторизованных пользователей.

При переходе по прямой ссылке на страницу ингредиента или заказа отображается полноценная страница с соответствующей информацией.

### Модальные окна

Реализованы модальные окна для отображения подробной информации об ингредиентах, заказах и результате оформления заказа.

Предусмотрено закрытие модальных окон по клику на крестик и оверлей.

Для навигации к ингредиентам и заказам используются динамические маршруты.

### Лента заказов

Реализована страница общей ленты заказов, доступная всем пользователям.

#### Отображаются:

-Список заказов.

-Номера заказов.

-Статусы выполнения.

-Стоимость каждого заказа.

-Общее количество заказов.

-Количество выполненных заказов за день.

Данные обновляются в режиме реального времени.

## Тестирование

Для проверки корректности работы приложения используются Jest и Playwright.

### Юнит-тестирование (Jest):

Проверка редьюсера слайса ингредиентов.

Проверка редьюсера конструктора бургера.

Проверка обработки обычных и асинхронных экшенов.

Проверка начального состояния и неизвестных экшенов.

### Интеграционное тестирование (Playwright):

Проверка загрузки ингредиентов с использованием моковых данных.

Проверка добавления ингредиентов в конструктор.

Проверка открытия и закрытия модальных окон.

Проверка оформления заказа.

Проверка отображения номера заказа.

Проверка очистки конструктора после оформления заказа.

## Запуск проекта

Клонировать репозиторий:

bash

git clone <ссылка-на-репозиторий>

Перейти в папку проекта:

bash

cd stellar-burgers

Установить зависимости:

bash

npm install

Создать файл .env на основе .env.example и указать адрес API:

env

BURGER_API_URL=<адрес-api>

Запустить приложение:

bash

npm run start
