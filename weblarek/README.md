# Web-Larёk

Web-Larёk — интернет-магазин товаров для веб-разработчиков, в котором пользователи могут просматривать каталог товаров, знакомиться с подробной информацией о продуктах, добавлять товары в корзину и оформлять заказы.

Приложение реализовано с использованием TypeScript и построено на архитектуре MVP (Model-View-Presenter), обеспечивающей разделение логики работы с данными, пользовательского интерфейса и управления взаимодействием между ними.

## О проекте

Основная задача проекта — разработать полноценное клиентское приложение интернет-магазина с каталогом товаров, корзиной покупок и многоэтапным оформлением заказа.

Пользователь может выбрать интересующие товары, просмотреть их характеристики, управлять содержимым корзины, указать контактные данные и способ оплаты, а затем отправить заказ на сервер.

Взаимодействие между компонентами приложения реализовано с помощью событийно-ориентированного подхода.

## Основной функционал

-Загрузка и отображение каталога товаров с сервера.

-Просмотр подробной информации о выбранном товаре.

-Отображение товаров в виде карточек.

-Добавление товаров в корзину.

-Удаление товаров из корзины.

-Проверка наличия товара в корзине.

-Автоматическое обновление счётчика товаров.

-Подсчёт общей стоимости заказа.

-Очистка корзины.

-Оформление заказа в несколько этапов.

-Выбор способа оплаты: банковская карта или наличные.

-Ввод адреса доставки.

-Ввод контактных данных покупателя: email и телефон.

-Валидация полей форм.

-Отображение ошибок при некорректном заполнении.

-Отправка заказа на сервер.

-Отображение экрана успешного оформления заказа.

-Управление модальными окнами.

## Особенности реализации

### Архитектура приложения

Приложение построено на архитектурном паттерне MVP (Model-View-Presenter).

Архитектура разделяет приложение на три основных слоя:

#### Model (Модель)

Отвечает за хранение и обработку данных приложения.

##### Реализованы модели:

ProductCatalog — управление каталогом товаров.

ShoppingCart — управление корзиной покупок.

Buyer — хранение и валидация данных покупателя.

#### View (Представление)

Отвечает за отображение информации и взаимодействие пользователя с интерфейсом.

##### Реализованы компоненты:

Header — шапка приложения.

Gallery — галерея товаров.

CardCatalog — карточка товара в каталоге.

CardPreview — подробный просмотр товара.

Basket — корзина покупок.

CardBasket — карточка товара в корзине.

Order — форма оформления заказа.

Contacts — форма контактных данных.

Modal — универсальное модальное окно.

Success — экран успешного оформления заказа.

#### Presenter (Презентер)

Отвечает за взаимодействие между моделями и представлениями, обрабатывает пользовательские события и управляет логикой приложения.

## Управление событиями

Для организации взаимодействия между компонентами используется класс EventEmitter, реализующий паттерн «Наблюдатель».

Компоненты генерируют события при действиях пользователя или изменении данных, а подписчики обрабатывают эти события и обновляют интерфейс.

### Основные события приложения:

catalog:changed — обновление каталога.

card:preview — просмотр товара.

card:add — добавление или удаление товара из корзины.

basket:open — открытие корзины.

cart:changed — изменение содержимого корзины.

order:open — начало оформления заказа.

order:submit — отправка формы заказа.

contacts:open — переход к вводу контактных данных.

contacts:submit — отправка контактных данных.

order:success — успешное оформление заказа.

validation:changed — изменение состояния валидации форм.

## Работа с API

Для взаимодействия с сервером используется класс Api, реализующий базовую логику HTTP-запросов.

Класс ShopApi отвечает за получение каталога товаров и отправку заказов.

### Реализованы следующие операции:

Получение списка товаров с сервера.

Создание заказа с передачей данных покупателя и выбранных товаров.

Обработка ответов сервера и ошибок запросов.

## Управление корзиной

Корзина реализована в отдельной модели ShoppingCart.

Предусмотрены добавление и удаление товаров, проверка наличия товара, подсчёт количества позиций и общей стоимости заказа.

При изменении содержимого корзины автоматически обновляется счётчик в шапке приложения.

## Оформление заказа

Оформление покупки реализовано в виде последовательного процесса:

Пользователь добавляет товары в корзину.

Переходит к оформлению заказа.

Выбирает способ оплаты и указывает адрес доставки.

Заполняет контактные данные: email и телефон.

Проходит проверку введённых данных.

Отправляет заказ на сервер.

Получает подтверждение успешного оформления заказа.

После успешной отправки заказа корзина очищается, а пользователю отображается экран с информацией о списании средств.

## Валидация форм

Для проверки корректности данных покупателя используется модель Buyer.

Реализована проверка обязательных полей, адреса доставки, способа оплаты, электронной почты и номера телефона.

Состояние кнопок отправки и сообщения об ошибках обновляются в зависимости от корректности введённых данных.

## Модальные окна

Для отображения дополнительной информации используется универсальный компонент Modal.

### Через модальные окна реализованы:

Просмотр подробной информации о товаре.

Отображение содержимого корзины.

Заполнение формы заказа.

Ввод контактных данных.

Подтверждение успешного оформления покупки.

##Базовые компоненты

Для построения интерфейса используется базовый класс Component, от которого наследуются компоненты представления.

Он обеспечивает единый механизм рендеринга данных и работы с DOM-элементами.

## Технологический стек

### Основные технологии:

HTML5 — структура приложения.

TypeScript — типизация и разработка логики приложения.

SCSS — стилизация интерфейса.

Vite — сборка и запуск проекта.

### Архитектура и принципы разработки:

MVP (Model-View-Presenter) — разделение ответственности между слоями приложения.

EventEmitter — событийно-ориентированное взаимодействие компонентов.

ООП — организация кода с помощью классов и наследования.

TypeScript Interfaces — описание структуры данных и контрактов компонентов.

## Установка и запуск

Клонировать репозиторий:

bash

git clone <ссылка-на-репозиторий>

Перейти в папку проекта:

bash

cd web-larek

Установить зависимости:

bash

npm install

Запустить проект в режиме разработки:

bash

npm run dev

Или с использованием Yarn:

bash

yarn yarn dev

Сборка проекта

Для создания production-сборки выполнить:

bash

npm run build

Или:

bash

yarn build
