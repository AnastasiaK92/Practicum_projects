# Закрывающий тег

«Закрывающий тег» — адаптивный веб-сайт, посвящённый личному опыту, сомнениям и трудностям, возникающим в процессе обучения и освоения новых навыков.

Проект представляет собой тематическую страницу с текстовыми публикациями, иллюстрациями и интерактивными элементами. Основная задача — создать визуально выразительный интерфейс, адаптированный под различные устройства, с использованием CSS-анимаций и SVG-графики.

## О проекте

В рамках проекта реализована вёрстка сайта по готовому макету Figma.

### Разработка выполняется поэтапно:

Создание статичной версии страницы.

Адаптация интерфейса под различные размеры экранов.

Добавление анимаций и интерактивных эффектов.

Особое внимание уделено точному соответствию макету, адаптивности, типографике и визуальным деталям.

## Основной функционал

Отображение тематических публикаций с текстом и изображениями.

Адаптивное отображение страницы на мобильных устройствах, планшетах и компьютерах.

Использование SVG-графики и векторных элементов.

Анимация интерактивных элементов интерфейса.

Интерактивная кнопка с эффектом изменения состояния при наведении.

Использование SVG-иконки дискеты в интерфейсе.

Отображение тематических изображений и декоративных элементов.

Поддержка фавиконок для различных браузеров и устройств.

## Особенности реализации

### Адаптивная вёрстка

Интерфейс разработан с учётом различных разрешений экранов.

Используются CSS Media Queries для изменения расположения элементов, размеров блоков и типографики в зависимости от ширины устройства.

### Анимации и интерактивность

Для создания динамических эффектов используются CSS-анимации и переходы.

Реализованы визуальные состояния интерактивных элементов, включая эффекты наведения и нажатия.

### Работа с SVG

В проекте используются векторные изображения для сохранения качества графики при масштабировании.

SVG-иконка дискеты преобразована в символ (symbol) и используется через механизм SVG <use>.

### Оптимизация изображений

Графические ресурсы подготовлены для использования в веб-приложении.

Для поддержки различных устройств предусмотрены:

-ICO-фавикон для совместимости с браузерами.

-SVG-фавикон для современных браузеров.

-PNG-фавикон для устройств Apple iOS.

### Организация стилей

Стили проекта вынесены в отдельную директорию styles/.

Для оформления страницы используются современные возможности CSS: адаптивные размеры, позиционирование, псевдоклассы, псевдоэлементы и анимации.

## Технологический стек

### Основные технологии:

HTML5 — семантическая структура страницы.

CSS3 — стилизация и оформление интерфейса.

CSS Grid — построение сеток и расположение элементов.

Flexbox — создание гибких компоновок.

CSS Media Queries — адаптивная вёрстка.

CSS Animations и Transitions — анимация интерфейса.

SVG — работа с векторной графикой.

### Инструменты разработки:

Figma — работа с макетом.

Git — контроль версий.

GitHub — хранение исходного кода.

GitHub Actions — автоматизация процессов проекта.

## Структура проекта

.github/workflows/ — конфигурация автоматизации GitHub Actions.

fonts/ — файлы шрифтов.

images/ — изображения проекта.

scripts/ — JavaScript-файлы.

styles/ — таблицы стилей CSS.

svg/ — SVG-иконки и векторная графика.

index.html — главная HTML-страница.

README.md — документация проекта.
