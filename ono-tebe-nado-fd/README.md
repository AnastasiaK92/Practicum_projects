# ono-tebe-nado-fd

Оно тебе надо — одностраничный сайт, созданный в рамках первого учебного проекта по frontend-разработке в Яндекс Практикуме.

## О проекте

Проект представляет собой статическую веб-страницу, свёрстанную по готовому макету.

Основная задача — освоить основы HTML и CSS, научиться работать со структурой документа, оформлением секций и расположением элементов на странице.

Работа над проектом строилась по принципу прогрессивного JPEG: сначала создавалась базовая структура всей страницы, затем последовательно прорабатывались и детализировались отдельные секции.

## Реализовано

-Создана базовая HTML-структура документа.

-Выполнена вёрстка всех секций страницы по макету.

-Добавлены изображения и пользовательские шрифты.

-Реализовано оформление элементов с помощью CSS.

-Организована структура файлов и ресурсов проекта.

## Технологии

-HTML5 — семантическая разметка страницы.

-CSS3 — стилизация и оформление элементов.

-Flexbox — расположение элементов (если используется в проекте).

-CSS Grid — построение сеток (если используется в проекте).

## Структура проекта

-index.html — HTML-разметка страницы.

-styles/ — таблицы стилей.

-images/ — изображения и графические ресурсы.

-fonts/ — пользовательские шрифты.

-.github/workflows/ — настройки GitHub Actions.
