# sales-bonus

Пряники — JavaScript-приложение для анализа продаж и расчёта бонусов продавцов на основе данных о доходности.

## О проекте

Проект представляет собой программу для обработки данных о продажах в магазине. На основе предоставленных датасетов приложение рассчитывает доходность продавцов, формирует рейтинг по результатам продаж и определяет размер бонусов для каждого сотрудника.

Основная задача — реализовать алгоритм анализа данных и расчёта бонусов с использованием чистого JavaScript без сторонних библиотек.

## Основной функционал

-Обработка данных о продажах из датасетов.

-Расчёт прибыли продавцов.

-Формирование рейтинга продавцов по доходности.

Р-асчёт бонусов на основе результатов продаж.

-Поддержка нескольких наборов входных данных.

## Особенности реализации

### Работа с данными

Реализована обработка массивов с данными о продажах и выполнение расчётов на их основе.

### Декомпозиция бизнес-логики

Основная функция анализа разделена на отдельные функции для расчёта прибыли и бонусов. Такой подход позволяет изменять отдельные правила расчёта без необходимости переписывать основную логику программы.

### Функциональный подход

-Использование чистых функций.

-Передача необходимых данных через аргументы.

-Отсутствие обращения к глобальным переменным внутри вычислительных функций.

-Минимизация побочных эффектов.

## Технологии

-JavaScript (ES6+) — обработка данных и реализация бизнес-логики.

-HTML5 — подключение скриптов и запуск приложения.

-Сторонние библиотеки не используются.

# Структура проекта

data/ — примеры датасетов с данными о продажах.

src/main.js — основная логика анализа данных и расчёта бонусов.

index.html — точка входа для запуска приложения.

## Запуск проекта

Клонировать репозиторий:

bash

git clone https://github.com/AnastasiaK92/sales-bonus.git

Перейти в папку проекта:

bash

cd sales-bonus

Открыть файл index.html в браузере.

Результаты анализа, рейтинг продавцов и рассчитанные бонусы выводятся в консоль разработчика браузера (DevTools).
