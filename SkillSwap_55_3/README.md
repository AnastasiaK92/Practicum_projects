# SkillSwap

SkillSwap — веб-платформа для обмена навыками и знаниями между пользователями. Сервис помогает находить людей с интересующими компетенциями, делиться собственным опытом и организовывать взаимовыгодный обмен знаниями.

Проект разработан командой в рамках обучения в Яндекс Практикуме.

## О проекте

Идея SkillSwap — создать пространство, в котором пользователи могут предлагать свои навыки, находить интересующие их компетенции у других участников и обмениваться знаниями.

Платформа объединяет каталог навыков, пользовательские профили и инструменты взаимодействия между участниками.

## Основной функционал

-Каталог навыков с поиском, фильтрацией и сортировкой.

-Просмотр подробной информации о предложениях пользователей.

-Пользовательские профили.

-Регистрация и авторизация.

-Создание и просмотр предложений навыков.

-Добавление предложений в избранное.

-Система уведомлений.

-Обработка состояний загрузки, ошибок и пустой выдачи.

### Архитектура проекта

Проект организован с использованием архитектурного подхода Feature-Sliced Design (FSD).

## Основные директории:

-app/ — инициализация приложения и провайдеры.

-entities/ — бизнес-сущности: пользователи, навыки и запросы.

-features/ — функциональные модули приложения.

-pages/ — страницы приложения.

-shared/ — общие компоненты, типы и утилиты.

-widgets/ — составные блоки интерфейса.

## Управление состоянием

Для управления глобальным состоянием используется Redux Toolkit.

Взаимодействие с хранилищем осуществляется через типизированные хуки useAppDispatch и useAppSelector.


## Запуск проекта

Клонировать репозиторий:

bash

git clone https://github.com/AnastasiaK92/Practicum_projects.git

Перейти в директорию проекта:

bash

cd Practicum_projects/SkillSwap_55_3

Установить зависимости:

bash

npm install

Запустить приложение:

bash

npm run dev

Приложение будет доступно по адресу http://localhost:5173.
