#Структура репозитория

В репозитории собраны учебные и командные проекты, выполненные в рамках обучения в Яндекс Практикуме.

## SkillSwap 
Веб-платформа для обмена навыками и знаниями между пользователями.

## blog-customizer 
Веб-приложение для настройки внешнего вида страницы блога.

## ono-tebe-nado-fd 
Одностраничный сайт, созданный по готовому макету с использованием HTML и CSS.

## posmotri-v-okno-fd 
Веб-приложение для поиска и просмотра видеороликов с видами разных городов.

## sales-bonus 
JavaScript-приложение для анализа продаж, формирования рейтинга продавцов и расчёта бонусов.

## slozhno-sosredotochitsya-fd 
Адаптивный сайт о концентрации внимания с поддержкой светлой и тёмной тем оформления.

## smart-table 
Интерактивная таблица для просмотра, сортировки и фильтрации данных о продажах.

## Stellar Burgers 
Веб-приложение космической бургерной с конструктором бургеров, авторизацией и оформлением заказов.

## Web-Larёk —
Интернет-магазин товаров для веб-разработчиков с каталогом, корзиной и оформлением заказов.

## Закрывающий тег 
Адаптивный сайт о процессе обучения с CSS-анимациями и SVG-графикой.
